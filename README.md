
 React in 30 Days – Landing Page

A fully responsive product landing page for the "Learn React in 30 Days" online course.
This project demonstrates **modern web design practices** with smooth animations, interactivity, and clean layouts.

 Features

* **Hero Section** with animated background, headline, and call-to-action button
* About Section describing the course with responsive layout
* Features Section (grid/cards with icons and hover effects)
* Testimonials Section with multiple student reviews and avatars
* Contact Section with a simple form (name, email, message)
* Sticky Navbar with smooth scrolling navigation
* Subtle Background Animation (floating circles / gradient animation)
* Hover Effects on buttons & cards for interactivity
* Mobile Menu Toggle using JavaScript

 Tech Stack

* HTML5 for semantic structure
* CSS3 (Flexbox & Grid for responsive design
* JavaScript (Vanilla for interactivity
* Optional: AOS.js / CSS keyframes for scroll animations

Responsiveness

* Desktop: multi-column layout
* Tablet: adaptive sections
* Mobile: stacked layout with toggle menu
